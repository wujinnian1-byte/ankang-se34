# 部署说明

在线预览：https://wutiantian.cn/ankang/

## 域名根目录

将 `dist/` 的内容部署为静态网站根目录，保持全部子目录结构，默认首页设为 `index.html`。没有服务端程序，也不需要框架构建。

## 独立子路径

项目默认包含绝对路径。部署到 `/ankang/` 时，先执行：

```sh
python3 scripts/build_ankang_subpath.py
```

上传 `output/ankang-site/` 内容到独立目录。Nginx 示例：

```nginx
location = /ankang { return 301 /ankang/; }
location ^~ /ankang/ {
    alias /var/www/ankang/;
    index index.html;
    autoindex off;
    charset utf-8;
    add_header Cache-Control "no-cache" always;
}
```

把示例中的 alias 改成实际目录。不要将现有站点的根目录替换为该项目；独立 location 可以与原首页共存。

其他子路径需要修改 `scripts/build_ankang_subpath.py` 中的前缀。静态文件需正确提供 MIME 类型，图片、字体、视频、GLTF 与 BIN 文件均须一并上传。不存在的素材应返回 404，不要统一重写成首页 HTML。

## 更新流程

本地修改 → 校验 → 构建对应路径版本 → 上传新发布目录 → 核验 → 切换专用目录。保留上一版以便恢复。不要提交服务器凭证、部署密钥、浏览器状态或缓存。
